# Frontend

SvelteKit application with adapter-static for AsistCV.

## Stack

- SvelteKit
- TypeScript
- npm (package manager)

## Commands

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Run tests
npm run test
```

## Structure

```
frontend/
├── src/           # Source code
├── static/        # Static assets
└── package.json   # Project configuration
```
